# Post Views (v2.1.1)

一款轻量、高颜值、高性能的 WordPress 文章浏览量统计与热门排行榜插件。

## 🌟 核心特性

- **多周期排行榜大屏**：支持「今日热门」、「本周热门 (近7天)」、「本月热门 (近30天)」与「历史总榜 (全量累计)」，配备金银铜专属榜首勋章与走势指标。
- **9 款现代化视觉预设**：现代简洁、极简数字、极简线性、复古轻奢、海去动感、轻奢圆角、赛博霓虹、霓红渐变、黑曜石圆边，全响应式适配与原生暗色模式。
- **高并发与防刷引擎**：
  - 支持 **PV 模式** 与 **24小时 UV 去重模式**。
  - **有效阅读过滤**：支持自定义最低停留时长（秒）与滚动深度（%），智能过滤秒退访客。
  - **内存缓冲池**：启用 Redis / Memcached 等外部对象缓存时，通过原子递增的内存计数器聚合批量落库，彻底避免 MySQL 行锁争用（无外部对象缓存时自动直写，不会丢数）。
  - **轻量传输协议**：支持原生 REST API 与经典 AJAX 双通道上报。
- **独立周期统计表**：采用独立表 `wp_post_views_stats` 存储高精周期数据，支持 35 天高频数据滚动自动清理，轻量无冗余。
- **文章字数与预估阅读时长**：内置精准中英文分词算法，支持 `%READ_TIME%` 与 `%WORD_COUNT%` 占位符。
- **站长运营与底数运维**：文章编辑页侧边栏单篇校正、全局初始底数 (Offset)、虚拟倍率与一键历史基准同步。
- **第三方主题无缝兼容**：原生兼容 JustNews 等主流主题的文章列表卡片与阅读量开关，零冲突即插即用。
- **全生态适配**：全面支持 Gutenberg 原生区块、经典小工具、短代码及模板函数调用。

## 🚀 快速上手

### 1. 自动显示
插件启用后，会自动在已勾选的文章/页面正文下方渲染浏览量卡片，无需修改任何代码。

### 2. 模板函数调用
在主题模板文件（如 `single.php`）中手动输出当前文章浏览量：
```php
<?php if ( function_exists( 'the_views' ) ) { the_views(); } ?>
```

获取指定周期的热门文章排行（支持 `today`、`week`、`month`、`all`）：
```php
<?php if ( function_exists( 'get_trending_posts' ) ) { get_trending_posts( 'week', 'post', 10 ); } ?>
```

### 3. 短代码 (Shortcodes)
- 当前文章浏览量：
  ```text
  [views]
  ```
- 周期热门榜单：
  ```text
  [trending_views period="today" limit="5"]
  [trending_views period="week" limit="10"]
  [trending_views period="month" limit="10"]
  [trending_views period="all" limit="10"]
  ```

### 4. 前端 URL 排序
在文章归档或分类页面通过 URL 参数按浏览量排序：
```text
?v_sortby=views&v_orderby=desc
```

## 📋 模板变量占位符

在后台「显示与外观预设」中，可自由组合以下变量自定义 HTML 模板：

| 变量 | 说明 | 示例 |
| :--- | :--- | :--- |
| `%VIEW_COUNT%` | 格式化的浏览量数字 | `1,234` |
| `%VIEW_COUNT_ROUNDED%` | 缩略格式数字 | `1.2K`、`3.5M` |
| `%READ_TIME%` | 预估阅读时长 | `3 分钟` |
| `%WORD_COUNT%` | 文章中英文总字数 | `1,520 字` |
| `%POST_TITLE%` | 文章标题（榜单列表可用） | `示例文章标题` |
| `%POST_URL%` | 文章链接（榜单列表可用） | `https://...` |
| `%POST_DATE%` | 文章发布日期 | `2026-10-12` |
| `%POST_THUMBNAIL%` | 文章封面缩略图 HTML | `<img ...>` |

## 🖥️ 后台管理入口

### 1. 文章浏览量排行榜面板
- **路径**：WordPress 后台 → **文章** → **浏览量排行** (`edit.php?page=post-views-stats`)
- **功能**：
  - 全站阅读指标概览（今日全站量、近 7 天全站量、周期统计表记录数）。
  - 四大时间周期即点即切：今日热门榜、本周热门榜 (近7天)、本月热门榜 (近30天)、历史总榜。
  - 金银铜前三名专属勋章、文章封面、周期与累计阅读量、作者及文章快速编辑/查看直达链接。

### 2. 浏览量设置面板
- **路径**：WordPress 后台 → **设置** → **浏览量设置** (`options-general.php?page=post-views`)
- **包含 5 大独立配置模块**：
  1. **🎨 显示外观预设**：9 款预设样式直观选定、内容类型勾选、各页面（首页/详情页/归档等）显示权限矩阵、自定义模板。
  2. **📊 周期榜单与统计**：周期数据明细状态、仪表盘首页 Top 5 榜单小工具开关、WP_Query 参数调用说明。
  3. **🚀 高并发与防刷引擎**：PV / UV 统计模式切换、有效阅读判定（停留时间/滚动深度门槛）、REST API / AJAX 协议选择、高并发对象缓存缓冲池阈值。
  4. **🧩 区块与阅读时长**：Gutenberg 原生区块指南、短代码生成、每分钟阅读字数 (WPM) 设置。
  5. **🛠️ 初始底数与数据运维**：全局初始底数 (Offset)、虚拟倍率、文章编辑页侧边栏 Meta Box、一键同步历史数据为初始基准、跨插件历史数据一键迁移。

## 🔌 第三方主题无缝兼容（如 JustNews 等）

许多第三方主题（如 JustNews）原生读取 WP-Postviews 的配置与字段，本插件已进行底层全兼容：

- **函数探测**：完整提供 `the_views()` 与 `get_post_views()` 全局函数。
- **显隐判断**：实现 `should_views_be_displayed( $options )`，遵循插件内的显隐规则。
- **列表卡片数字**：通过 `the_posts` 过滤器为 `$post->views` 批量注入加权运算后的浏览数值，列表卡片与文章内页数字严格一致。
